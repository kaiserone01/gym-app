# Handoff — gym-app

## 1. Objetivo
Panel administrativo (`apps/web-admin`) de un sistema de gestión de gimnasio: miembros, pagos, y un módulo de Caja (apertura/cierre de turno con arqueo, en USD y bolívares).
Host de escritorio Windows `apps/kiosk-host` (WinForms + WebView2 + Raw Input) para que el numpad RAIKU K-601 alimente solo al kiosco (`apps/kiosk`), sin drivers ni admin.
